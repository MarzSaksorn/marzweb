# 🎮 GameHub — ศูนย์รวมเกม

A browser-based game hub that collects classic and fun games in one place, localized into Thai for easy access.

**Live site:** [MarzSaksorn/Gamehub on Marzweb](https://www.marzweb.win/Gamehub/)

---

## 🕹️ Games Available

| Game | Description |
|------|-------------|
| **Minesweeper** | Classic grid-based mine-detection puzzle |
| **2048** | Slide numbered tiles to reach the 2048 tile |
| **Sudoku** | Fill a 9×9 grid so every row, column, and box contains 1–9 |
| **Wordle** | Guess the hidden 5-letter word in 6 tries |
| **Rock Paper Scissors** | Classic hand-game against the computer |
| **Tic-Tac-Toe Multiplayer** | Two-player Tic-Tac-Toe in the browser |
| **Flappy Bird** | Navigate a bird through pipes by tapping/clicking |
| **Whac-a-Mole** | Hit the moles as they pop up before time runs out |
| **Color Flood** | Flood-fill the board with a single color in limited moves |
| **Tap Tap Tap** | Rhythm-style tapping game |
| **Tetris** | Arrange falling blocks to clear lines |
| **Stack Game** | Stack moving blocks as precisely as possible |

---

## 🚀 Getting Started

This project is a static website — no build step is required.

1. **Clone the repository**
   ```bash
   git clone https://github.com/MarzSaksorn/Gamehub.git
   cd Gamehub
   ```

2. **Open `index.html`** directly in your browser
